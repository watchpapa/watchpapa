## Keeping these accurate

- Update [../CONTEXT.md](../CONTEXT.md) after any meaningful code change (project rule), and the matching document here when it touches deployment, the schema, plans/rewards, announcements or security.
- When a migration changes tables, policies or functions, re-run the queries at the bottom of [database/schema.md](database/schema.md).
- The `*_GOOGLE_DOCS.txt` files are plain-text twins of the Markdown compliance documents. Edit both together.
- Do not document things that no longer exist. Superseded material belongs in git history, not here.
